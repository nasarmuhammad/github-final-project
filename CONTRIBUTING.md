# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for helping improve the Simple Interest Calculator!

## How to contribute

1. Review the [Code of Conduct](CODE_OF_CONDUCT.md) before participating.
2. Open an issue describing a bug or proposed improvement, including enough details to reproduce any problem.
3. Fork the repository and create a descriptively named branch.
4. Make a focused change; update documentation or add tests as appropriate.
5. Test the script locally using `bash simple-interest.sh` (requires the `bc` utility).
6. Commit your changes with a descriptive message and open a pull request against the `main` branch.
7. Explain what changed and how it was tested. Respond respectfully to review feedback.

Please avoid including secrets, credentials, or private information in bug reports or pull requests.

## Reporting bugs

Include the input values, the output you observed, and the expected output. For example, principal `1000`, time `2` years, and rate `5` percent should produce interest `100.00`.
